Este é o meu portfólio pessoal com uma estética futurista/cyberpunk, focado em apresentar minhas habilidades como Desenvolvedor Backend. O projeto utiliza efeitos de Glassmorphism, animações em Canvas e um design responsivo otimizado para uma experiência de "Agente de Sistemas".

🛠️ Tecnologias Utilizadas
Frontend: HTML5, CSS3 (Custom Variables & Flexbox/Grid)

Interatividade: JavaScript Vanilla (Efeito de partículas e animações)

Estilização: Glassmorphism & Neon Design

Ícones: FontAwesome 6.0

🌌 Funcionalidades
Efeito de Partículas: Fundo animado utilizando a API Canvas do JavaScript.

Seção Sobre: Espaço dedicado para perfil, biografia técnica e stack de linguagens.

Galeria de Projetos: Cards interativos com efeitos de hover e links para repositórios.

Hub de Contatos: Seção estilizada para conexão rápida via LinkedIn, E-mail e GitHub.

Totalmente Responsivo: Adaptado para dispositivos móveis, tablets e desktops.
